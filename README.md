# 🚨 Emergency Resource Matcher

**Right Help. Right Resource. Right When It Matters.**

## 📌 About the Project

Emergency Resource Matcher is a Java-based application that connects people in need with verified emergency resource providers, including blood donors, oxygen suppliers, ambulance providers and volunteers.

It uses smart matching techniques to find suitable providers based on availability, location, blood group compatibility and urgency.

## 🎯 Objectives

- Make emergency resource searching easier.
- Connect people with verified providers.
- Reduce delays in emergency situations.
- Prioritize the most suitable available resources.
- Maintain emergency request history.

## ✨ Key Features

- User Registration and Login
- Admin Verification System
- Blood Donor Management
- Oxygen Supplier Management
- Ambulance Management
- Volunteer Management
- Emergency Request Creation
- Smart Resource Matching
- Blood Group Compatibility Checking
- Priority-Based Matching
- Request Status Tracking
- Donor Cooldown Management
- Emergency History and Reports

## 🛠️ Technologies Used

- **Language:** Java
- **Concepts:** Object-Oriented Programming (OOP)
- **DSA:** Arrays and Java Collections Framework
- **Collections:** ArrayList, LinkedList, HashMap, HashSet, TreeMap, PriorityQueue
- **Advanced Concepts:** Exception Handling, Multithreading and Synchronization
- **Interface:** Java Terminal / Console
